# npm 0.4.6 Release Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Synchronize both remote develop branches with master and prepare verified npm release artifacts for wjx-api-sdk, wjx-mcp-server, and wjx-cli at 0.4.6.

**Architecture:** Preserve both remote branch histories without force pushes. Use the current master source tree as the release baseline; do not restore the obsolete nested repository from GitHub develop. Validate and package the three npm workspaces in SDK → MCP Server → CLI order.

**Tech Stack:** Git, npm workspaces, Node.js, TypeScript, node:test, Python unittest.

---

### Task 1: Synchronize develop

- Fast-forward local develop to Codeup develop, merge master, and retain the legacy GitHub develop history with an ours merge.
- Verify `git diff --exit-code master develop` and ensure both remote develop tips are ancestors of local develop.
- Push develop to Codeup and GitHub using ordinary fast-forward pushes.

### Task 2: Verify release metadata and dependencies

- Check the official npm registry, authenticated npm account, all three package versions, internal dependency ranges, and package-lock consistency.
- Install the exact lockfile with `npm ci` and run the dependency audit required by CI.
- Keep the existing 0.4.6 version if it is still unpublished; avoid unrelated dependency or feature changes.

### Task 3: Run release gates

- Run SDK, MCP Server, and CLI test suites, in that order, to avoid concurrent rebuilding of shared artifacts.
- Run the capability, documentation, generated docs, CLI architecture, manifest, protocol, bundled skill, startup performance, and release artifact gates used by `.github/workflows/cli.yml`.
- Run the bundled PPT skill Python unittest suite.
- Investigate any failure before changing implementation, and rerun the affected checks after a fix.

### Task 4: Prepare distribution artifacts

- Review the 0.4.6 changelog entries against master changes since 0.4.5.
- Run npm publish dry runs and pack all three workspaces into a retained local artifact directory.
- Verify packaged versions, dependencies, entry points, and isolated installation; exclude credentials and development-only files.
- Record actual checks, package sizes, integrity hashes, artifact paths, and any remaining registry authentication requirement below.

### Task 5: Release and verify

- Publish the verified tarballs to `https://registry.npmjs.org` in SDK → MCP Server → CLI order when proceeding with the release.
- Update release dates and installation documentation only to reflect actual published state.
- Verify each registry version and latest tag, then verify a fresh registry installation.
- Commit release metadata and synchronize the relevant branches across both remotes.
