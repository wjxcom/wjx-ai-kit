# 问卷星计算公式指南

问卷星中的计算公式功能来源于Excel，但针对问卷场景做了适配。本指南覆盖题目引用规则、语法规范、函数参考、各题型推送数据格式以及实战案例。

## AI Agent 行为准则（必读）

### 规则 0：题目引用使用 [qN] 格式（强制）

问卷星中不能用 Excel 的单元格编号（A1、B2），必须使用 `[q1]`、`[q2]` 的形式引用题目。不同题型的引用后缀不同，**必须**根据题型选择正确的引用格式。

| 题型 | 引用格式 | 说明 |
|------|----------|------|
| 普通题（单选/多选/填空/量表/下拉） | `[q1]` | 直接引用题号 |
| 矩阵题（选项为行标题） | `[q1_1]` | `_1` 表示第1行，`_2` 表示第2行 |
| 表格题（行+列） | `[q1_1_1]` | 第1行第1列，`[q1_2_1]` 第2行第1列 |
| 评分题（获取分值） | `[q1_value]` | 获取评分分值而非选项文字 |
| 排序题（获取排序位置） | `[q1_1_sort]` | `_1_sort` 表示排序为1的选项 |
| 选择题允许填空 | `[q1_1_text]` | 获第1个选项的可填空内容 |
| 矩阵题允许填空 | `[q1_1_1_text]` | 矩阵第1行第1列的填空内容 |

### 规则 1：数值计算优先使用函数而非直接运算符

推荐使用 `SUM([q1],[q2])` 而不是 `[q1]+[q2]`，函数方式更稳定且更易读。


### 规则 2：数组必须双层 [] 包裹

Excel 的 `A1:A10` 在问卷星中写为 `[[q1],[q2],[q3]]`。外层 `[]` 包裹整个数组，每个元素也必须用 `[]` 包裹。二维数组用于 VLOOKUP 等场景：`[['张三','客服部'],['李四','销售部']]`。

### 规则 3：字符串统一用单引号包裹

所有字符串值必须使用单引号 `''` 包裹，如 `'北京'`、`'张三'`。不要使用双引号。

### 规则 4：评分题分值必须用 _value 后缀

设置了分值的题目（如评分单选题、矩阵量表题），计算时必须使用 `[q1_value]`、`[q1_1_value]` 获取分值，直接用 `[q1]` 拿到的是选项文字而非数值。

## 题目引用规范

### 基础引用

| Excel | 问卷星 |
|-------|--------|
| `A1` | `[q1]` |
| `SUM(A1,A2,B1)` | `SUM([q1],[q2],[q3])` |
| `COUNTIF(A1:B1,C1)` | `COUNTIF([['北京'],['天津']],[q1])` |

Excel中的单个单元格变为问卷中的具体题目序号；单元格数组需改写为特定的列表形式。

### 各题型引用后缀速查

```
单选题/多选题/填空题/下拉题/量表题:
  [q1]              → 第1题的值

矩阵题 (行标题=选项):
  [q1_1]            → 第1题第1行
  [q1_2]            → 第1题第2行

表格题 (行+列):
  [q1_1_1]          → 第1题第1行第1列
  [q1_2_1]          → 第1题第2行第1列
  [q1_1_2]          → 第1题第1行第2列

评分题:
  [q1_value]        → 第1题的分值
  [q2_value]        → 第2题的分值

排序题:
  [q1_1_sort]       → 第1题排序为1的选项
  [q1_2_sort]       → 第1题排序为2的选项

选择题允许填空:
  [q1_1_text]       → 第1题第1个选项的填空内容
  [q1_2_text]       → 第1题第2个选项的填空内容

矩阵题允许填空:
  [q1_1_1_text]     → 第1题第1行第1列的填空内容
```

## 核心语法规则

### 题目属性

获取的题目答案默认为**字符串**类型。需要作为数值运算时，可将题目属性验证设置为「整数」或「小数」。简单的加减乘除运算通常不需要设置属性验证即可直接计算。

### 数组写法

一维数组（如对表格题某行的每个列求和）：

```
SUM([[q1_1_1],[q1_1_2],[q1_1_3]])
```

二维数组（如 VLOOKUP 查找表）：

```
VLOOKUP([q1],[['张三','客服部'],['李四','销售部'],['王五','技术部']],2,0)
```

所有字符串值需用单引号 `''` 包裹。

## 函数参考

### 日期时间函数

#### YEARFRAC

计算两个日期之间的天数占一年的比例。

```
YEARFRAC(start_date,end_date,[basis])
```

| Basis | 日计数基准 |
|-------|-----------|
| 0 或省略 | US (NASD) 30/360 |
| 1 | 实际/实际 |
| 2 | 实际/360 |
| 3 | 实际/365 |
| 4 | 欧洲 30/360 |

#### DAYS

计算两个日期之间相隔的天数：

```
DAYS([q2],[q1])
```

#### DATEVALUE

将文本日期转换为日期值：

```
DATEVALUE([q1])
```

#### HOUR / MINUTE / SECOND

分别返回小时、分钟、秒数值：

```
HOUR([q1])
MINUTE([q1])
SECOND([q1])
```

### 数学计算函数

#### ROUND

四舍五入到指定小数位：

```
ROUND([q1],2)     → 四舍五入到2位小数
```

#### ROUNDUP

向上舍入（向绝对值增大的方向舍入）。

#### ROUNDDOWN

向下舍入（向绝对值减小的方向舍入）。

#### INT

对数值向下取整：

```
INT([q1])
```

#### MOD

返回两数相除的余数：

```
MOD([q1],36)
```

### 文本合并

#### CONCATENATE

将多个文本字符串合并为一个：

```
CONCATENATE([q1],'小时',[q2],'分钟')
```

### 条件判断

#### IF

```
IF(条件, 满足条件的结果, 不满足条件的结果)
```

示例：

```
IF([q1]>10,"大于10","小于或等于10")
```

#### 比较运算符

| 大于 | 大于等于 | 小于 | 小于等于 | 等于 | 不等于 |
|------|---------|------|---------|------|-------|
| `>` | `>=` | `<` | `<=` | `==` | `!=` |

注意：输入比较运算符时确保大写键关闭或将输入法切换至英文状态。

### 逻辑函数

#### AND

所有逻辑表达式都为 True 时返回 True：

```
AND([q1]>0,[q1]<10)    → q1在0到10之间
```

#### OR

任意一个逻辑表达式为 True 时返回 True：

```
OR([q1]=='5',[q1]=='10')    → q1等于5或10
```

### 查找统计函数

#### FIND

在文本中查找子串，返回起始位置（从1开始），找不到返回0：

```
FIND('北京',[q1])     → 选了"北京"返回1，否则返回0
```

#### COUNTIF

在给定的数组中对输入内容进行匹配，匹配成功返回1，否则返回0：

```
COUNTIF([['北京'],['上海'],['深圳']],[q1])
```
如果q1选中了北京、上海或深圳中任意一个，返回1，否则返回0。

## 实战案例

### 四则运算

**加法**（推荐用SUM）：

```
SUM([q1],[q2])
```

**减法**：

```
[q2]-[q1]
```

**乘法**：

```
[q2]*[q1]
[q1]* 0.2
```

**除法**：

```
[q2]/[q1]
[q2]/5
```

**幂运算**：

```
POWER([q1],2)
```

复合运算注意优先级，必要时用括号 `()`：

```
(SUM([q1],[q2])+100)/100
```

### 日期比较

使用 DAYS 函数判断填写者输入的日期是否符合规范：

```
DAYS([q2],[q1])
```

填空题设置日期和时间属性时，使用 DATEVALUE 转换为数值后比较：

```
DATEVALUE([q2])-DATEVALUE([q1])
```

### 工时计算

#### 天数计算

核心逻辑：使用 DAY 函数获取开始和结束日期的天数并相减。

- 结果=0：当天开始当天结束
- 结果>0：跨天，需判断是否满足24小时（86400秒）

```
IF((DAY([q2])-DAY([q1]))==0, 0,
   SUM((DAY([q2])-DAY([q1]))-1,
       QUOTIENT(SUM(86400-[q3],[q4]),86400)))
```

#### 小时/分钟/秒数转换

将时间转为秒数：`SUM(HOUR([q1])*3600, MINUTE([q1])*60, SECOND([q1]))`

计算差值后换算为时分秒：

**小时数**：

```
IF(([q4]-[q3])<0,QUOTIENT(SUM(86400-[q3],[q4]),3600),QUOTIENT([q4]-[q3],3600))
```

**分钟数**：

```
IF(([q4]-[q3])<0,QUOTIENT(MOD(SUM(86400-[q3],[q4]),3600),60),QUOTIENT(MOD([q4]-[q3],3600),60))
```

**秒钟数**：

```
IF(([q4]-[q3])<0,MOD(MOD(SUM(86400-[q3],[q4]),3600),60),MOD(MOD([q4]-[q3],3600),60))
```

**最终合并**：

```
CONCATENATE([q5],' 天 ',[q6],' 小时 ',[q7],' 分钟 ',[q8],' 秒 ')
```

提示：中间计算题可设置为隐藏状态。

### 年龄分层

在年龄段单选题中设置选项表达式，根据年龄填空题 `[q1]` 的值自动选中对应选项：

| 年龄段 | 公式 |
|--------|------|
| 18岁以下 | `[q1]<19` |
| 18-25岁 | `AND([q1]>18,[q1]<26)` |
| 26-35岁 | `AND([q1]>25,[q1]<36)` |
| 35岁以上 | `[q1]>35` |

### 人数控制

防止评价者给所有人打同样的分数（所有被评者处于同一档位）：

```
IF(SUM(COUNTIF([['9'],['10']],[q1_1]),
        COUNTIF([['9'],['10']],[q1_2]),
        COUNTIF([['9'],['10']],[q1_3]),
        ...
        COUNTIF([['9'],['10']],[q1_9])) > 8, 1, 0)
```

逻辑拆解：
1. COUNTIF 统计每个行标题是否选中了9或10分（选中返回1，未选返回0）
2. SUM 对9个 COUNTIF 结果求和
3. IF 判断：超过8人（即9人）均处于9-10分档位 → 意味着所有被评人在同一档
4. 替换分值时修改 `['9'],['10']` 为对应分值区间（如1-4档改为 `['1'],['2'],['3'],['4']`）
5. 调整控制人数时修改 `SUM()> 8` 中的阈值

### 日期/年龄计算

使用 YEARFRAC 计算两个日期间的年龄：

```
ROUNDDOWN(YEARFRAC([q7], '12/31/2024', 1), 0)
```

- YEARFRAC 计算 `[q7]` 到 `'12/31/2024'` 的天数占比后换算为年数
- ROUNDDOWN 对小数结果向下取整
- `[q7]` 支持年-月-日格式和年-月格式
- 截止日期 `'12/31/2024'` 可自由设置为任意日期

## 常见错误与处理

| 错误场景 | 原因 | 解决方案 |
|---------|------|---------|
| 公式计算结果不对 | 评分题直接用了 `[q1]` 而非 `[q1_value]` | 评分题必须用 `_value` 后缀获取分值 |
| 数组报错 | 缺少外层 `[]` 或元素无 `[]` | 确保格式：`[[q1],[q2],[q3]]`，字符串用单引号 |
| 判断逻辑格式错误 | 在判断逻辑中额外写了外层IF | 判断题直接写表达式即可（如 `[q1]>0`），系统已自动包裹IF |
| 赋值题目值不正确 | 赋值公式中引用了当前题目自身 | 赋值逻辑中当前题目不能参与计算 |
| 数值运算结果为NaN | 未设置题目属性验证 | 将题目属性设为「整数」或「小数」，或使用SUM等函数 |
| 矩阵/表格题引用不生效 | 后缀格式错误 | 矩阵用 `[q1_行号]`，表格用 `[q1_行号_列号]` |
| 矩阵填空/文本获取不到 | 使用了错误后缀 | 填空内容用 `_text` 后缀：`[q1_1_text]`，矩阵用 `[q1_1_1_text]` |
| 字符串比较不生效 | 用了双引号或没加引号 | 所有字符串值必须用单引号包裹：`'北京'` |
